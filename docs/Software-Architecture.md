# Software Architecture

# Heavy Equipment Maintenance Intelligence System (HEMIS)

---

## 1. Architecture Overview

HEMIS menggunakan arsitektur Three-Tier Architecture yang memisahkan aplikasi menjadi tiga lapisan utama.

1. Presentation Layer (Frontend)
2. Application Layer (Backend API)
3. Data Layer (Database)

---

## 2. Technology Stack

### Frontend

- React.js
- Tailwind CSS
- React Router
- Axios

### Backend

- Node.js
- Express.js
- JWT Authentication

### Database

- PostgreSQL

### Version Control

- Git
- GitHub
