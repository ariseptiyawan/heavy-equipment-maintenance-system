# Heavy Equipment Maintenance Intelligence System (HEMIS)

# User Manual

---

# 1. Introduction

This manual provides guidance for users of the Heavy Equipment Maintenance Intelligence System (HEMIS).

---

# 2. User Roles

## Administrator

Responsibilities

- Manage users
- Configure system
- View all reports

---

## Maintenance Supervisor

Responsibilities

- Schedule preventive maintenance
- Approve work orders
- Monitor maintenance progress

---

## Technician

Responsibilities

- View assigned work orders
- Update maintenance status
- Record repair results

---

## Warehouse Staff

Responsibilities

- Manage spare parts
- Record inventory transactions
- Monitor stock levels

---

## Management

Responsibilities

- View KPI Dashboard
- Analyze reports
- Monitor operational performance

---

# 3. Login

Steps

1. Open the application.
2. Enter username.
3. Enter password.
4. Click Login.
