# Heavy Equipment Maintenance Intelligence System (HEMIS)

## Overview

HEMIS (Heavy Equipment Maintenance Intelligence System) merupakan sistem manajemen maintenance alat berat yang dirancang untuk membantu perusahaan dalam mengelola aset, preventive maintenance, corrective maintenance, work order, inventory spare part, purchasing, serta monitoring KPI maintenance.

Project ini dibuat sebagai portofolio Software Engineering dan System Analysis.

---

## Main Features

- Dashboard Maintenance
- Asset Management
- Preventive Maintenance
- Corrective Maintenance
- Work Order
- Spare Part Inventory
- Purchasing
- KPI Dashboard
- Reporting
- User Management
