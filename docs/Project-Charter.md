# Heavy Equipment Maintenance Intelligence System (HEMIS)

## Project Overview

HEMIS (Heavy Equipment Maintenance Intelligence System) adalah aplikasi berbasis web yang dirancang untuk membantu perusahaan dalam mengelola aktivitas maintenance alat berat secara digital.

Sistem ini menyediakan monitoring kondisi unit, preventive maintenance, corrective maintenance, work order, inventory spare part, dashboard KPI, serta analisis performa maintenance.

HEMIS akan dikembangkan secara bertahap hingga mendukung integrasi IoT, Artificial Intelligence, dan Business Intelligence Dashboard.

---

## Project Goal

Membangun sistem maintenance alat berat yang modern, mudah digunakan, dan mampu membantu pengambilan keputusan berdasarkan data.
