# Heavy Equipment Maintenance Intelligence System (HEMIS)

# Contributing Guide

---

# 1. Introduction

Thank you for your interest in contributing to the Heavy Equipment Maintenance Intelligence System (HEMIS).

This guide explains how to contribute to the project.

---

# 2. Contribution Workflow

1. Fork the repository.
2. Create a new feature branch.
3. Implement your changes.
4. Commit your work.
5. Push the branch.
6. Submit a Pull Request.

---

# 3. Branch Naming

Examples

```
feature/login
feature/dashboard
bugfix/api
hotfix/security
```

---

# 4. Commit Message Convention

Examples

```
feat: add maintenance module

fix: inventory calculation

docs: update API documentation

refactor: improve dashboard service
```

---

# 5. Coding Standards

Frontend

- React.js
- Component-based architecture
- ESLint

Backend

- Express.js
- REST API
- MVC Pattern

Database

- PostgreSQL
- Third Normal Form (3NF)

---

# 6. Documentation

Every new feature should include:

- Documentation update
- API update
- Database update
- User manual update

---

# 7. Pull Request Checklist

- Code compiles successfully
- Documentation updated
- No critical bugs
- Tested before submission

---

# 8. Reporting Issues

Please include:

- Problem description
- Expected behavior
- Actual behavior
- Screenshots (if available)
- Steps to reproduce

---

# 9. Code Review

Every Pull Request will be reviewed before merging into the main branch.
